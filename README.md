# Fearless
### Every Girl Deserves to Live Fearless 

 A girls safety app that uses **discreet** safety measures.

### Features include:
- Discreet messaging system that sends SOS when keyword is sent
- Discreet SOS detection using vocal recognition CNN
- Livestream feature that acts as an offline saftey measure
- Live location and tracking

***This app is still in development***
